IBAN

About IBAN

This site explains the International Bank Account Number (IBAN): what it is, how it is laid out in each of the 89 countries that use it, and how to check that one is written correctly. The checker works inside your browser. The IBAN you type is not sent to us or to anyone else.

Where the data comes from

  • Length and layout of each country's IBAN, and the SEPA flag: the format table of the open-source schwifty library by Martin Domke (release 2026.11.0, MIT licence), which is generated from the IBAN Registry published by SWIFT, the registration authority for the IBAN standard (ISO 13616).
  • The check-digit method (remainder of division by 97) is part of the same public standard. The checker and the explanations are our own work.

Every example IBAN on this site is made up. Each has the right length, the right layout and correct IBAN check digits, so that you can see the pattern, but it is not a real account and must not be used for a payment.

How current it is

The layouts were last checked in November 2026. Countries join the IBAN registry from time to time. For a payment, always use the IBAN given by the account holder or printed by the bank.
