IBAN format of Belgium: 16 characters, starts with BE

An IBAN of Belgium is 16 characters long and begins with BE. Here is what each part means, a made-up example, and how to check one.

Made-up example (not a real account)

BE53 1234 5678 9012

  • 4567890Account number
  • 12National check digits

The parts with a name here are: Bank code, account number, national check digits. The bank decides the bank code and the account number; you never have to work them out yourself. The layout code BE2!n3!n7!n2!n is how the registry writes this: a number, then n for digits, a for capital letters or c for letters or digits.

How to check an IBAN of Belgium

  1. Count the characters without spaces. There must be exactly 16.
  2. The first two must be BE, and the next two must be digits.
  3. After those four, the rest must follow the layout: 3 digits, then 7 digits, then 2 digits.
  4. Run the check-digit test. The IBAN checker does all four steps for you and shows which one fails.

Writing it down

On paper, an IBAN is written in groups of four characters with spaces, as in the example above, so that it is easier to read and compare. In online banking and in files it is entered without spaces. Both forms are the same IBAN. Letters are always capitals.

How it compares

At 16 characters, it sits between the shortest IBAN in the registry (Norway, 15 characters) and the longest (Russia, 33 characters). After the country code it has digits only.

Common questions

How many characters does an IBAN of Belgium have?

An IBAN of Belgium always has 16 characters: the letters BE, two check digits and 12 more characters for the bank and the account.

What does an IBAN of Belgium start with?

It starts with BE, the country code, followed by two check digits.

Is Belgium in SEPA?

Yes. Belgium is part of the Single Euro Payments Area, so euro transfers to and from it use the IBAN.
